Express.js Basic Server & Routing 


📖 Assignment Description
Express.js ব্যবহার করে একটি সাধারণ সার্ভার তৈরি করতে হবে। সার্ভারটি নির্দিষ্ট একটি Port-এ রান করবে এবং মোট ৫টি Route তৈরি করতে হবে। প্রতিটি Route-এ JSON Response রিটার্ন করতে হবে।


✅ Requirements
১. Express.js ইনস্টল করুন।
২. server.js নামে একটি ফাইল তৈরি করুন।
৩. সার্ভারটি 5000 পোর্টে রান করুন।
৪. নিচের ৫টি Route তৈরি করুন।
