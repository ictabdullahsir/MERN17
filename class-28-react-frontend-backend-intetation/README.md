# React + Node.js/Express Project with JSON File Storage

This repository contains a full-stack integration of React (built with Vite) and Node.js/Express with persistent JSON storage.

## Structure

- `backend/`: Express server reading and writing to `data.json`.
- `frontend/`: React app fetching and updating users list via Express proxy.

## How to Run

1. **Backend:**
   ```bash
   cd backend
   npm install
   npm start
   ```

2. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
